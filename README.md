# Daily English

以《English for Everyday Activities》为主要参考，通过日常场景问答练习完整、准确、自然的英语表达。

## 目录结构

```text
daily-english/
├── README.md
├── AGENTS.md
├── progress.md
└── lessons/
    └── S1-Starting_the_day
```

| 文件 | 用途 | 何时更新 |
|---|---|---|
| [AGENTS.md](AGENTS.md) | 教练规则、学习目标、反馈风格 | 学习偏好改变时 |
| [progress.md](progress.md) | 当前主题、下次接续点、复习重点 | 完成实质练习后 |
| [lessons/](lessons/) | 问题、用户原回答、完整展开版、表达讲解 | 每次练习后追加 |
| README.md | 目录与使用说明 | 文件组织方式改变时 |

学习记录采用 `YYYY-MM-DD-topic.md` 命名。相同日期、相同主题追加到同一个文件；新日期或新主题创建新文件。保留原回答，不用修正版覆盖。

## 开始或恢复练习时可以说

> 请先读 AGENTS.md、progress.md 和进度中链接的最近一次学习记录，按我确认的方式继续陪我练习。每轮只问一个问题，帮我把回答展开得完整、准确、自然。

## 结束练习时可以说

> 请把今天的练习整理到 lessons 中，保留我的原回答、完整展开版和表达讲解，并更新 progress.md，写清楚下次从哪里继续。
